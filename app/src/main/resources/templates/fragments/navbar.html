DOCUMENTED INJECTION APPROACH (cited per T11 instructions): The Qute reference guide section "Injecting Beans Directly in Templates" states that {inject:} can only reference CDI beans annotated with @Named, and that beans which are NOT @Named must be exposed through an intermediate @Named CDI bean. ROOT PATH (W2): every href / hx-* below is prefixed with {config:['quarkus.http.root-path']}. Templates never hard-code the deployment root, so the app can be mounted anywhere by changing one property.
