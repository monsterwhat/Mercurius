{! pages/clientes/tabla - ONE data-table include for the Clientes module (W4B lane). Rendered standalone by GET /api/app/clientes/table when the HX-Request header is present (fragment swap) AND included by index.html — single source of truth for the markup (T18 pattern). Model (identical contract to pages/categorias/tabla-*.html): modelo Map - id, baseUrl, columnas(label/key), filas(Models.Clientes), sortKey, sortDir, page, size, total, totalPages, paginas, filtros(reserved keys excluded), q q String - current search text (round-tripped into the input) toastSeverity / toastMessage - optional OOB toast after row actions Columns mirror the legacy p:dataTable of secured/pages/Clientes/index.xhtml: status chip, Nombre, Dirección, Correo, Cédula, Teléfono, Tributario (Sí/No) + Acciones (Editar / Cambiar estado). Row actions: edit opens the shared modal via data-kit-open + hx-get; archive is the REST soft-delete (DELETE = status=false parity with ClientsController.toggleClient()). WHAT CHANGED IN THE UI PASS --------------------------- - The wrapper is a _kit/surface (no title: the panel has no heading). It KEEPS its id, because that element IS the hx-target of the search input and of the row actions - the swap replaces the whole surface. - The client code is an IDENTIFIER, so it is set in .kit-code and stays left-aligned; the old is-family-monospace was the second monospace class in the app. - The row actions are icon-only BORDERED buttons (kit icons, own aria-label). They used to carry is-success / is-warning, which put a second and a third accent hue on a screen whose only accent is teal. !} {#include _kit/surface id=modelo.id} {#content}
{#include _kit/icon name="search" /}
{#include _kit/data-table id=modelo.id baseUrl=modelo.baseUrl headers=modelo.columnas sortKey=modelo.sortKey sortDir=modelo.sortDir page=modelo.page size=modelo.size total=modelo.total totalPages=modelo.totalPages pages=modelo.paginas params=modelo.filtros} {#rows} {#for cliente in modelo.filas} {#if cliente.status??}Activo{#else}Inactivo{/if} {#if cliente.code??}{cliente.code}{#else}—{/if} {cliente.name} {#if cliente.address??}{cliente.address}{#else}—{/if} {#if cliente.email??}{cliente.email}{#else}—{/if} {#if cliente.idNumber??}{cliente.idNumber}{#else}—{/if} {#if cliente.phoneNumber??}{cliente.phoneNumber}{#else}—{/if} {#if cliente.taxpayer}Sí{#else}No{/if}
