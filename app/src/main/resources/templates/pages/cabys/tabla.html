{! pages/cabys/tabla - ONE data-table include for the CaByS catalog (W4B lane). Rendered standalone by GET /api/app/cabys/table when the HX-Request header is present (fragment swap into the page's table container) AND included by index.html — single source of truth for the markup (T18 pattern). Model (identical contract to pages/categorias/tabla-*.html): modelo Map - id, baseUrl, columnas(label/key), filas(Models.Cabys), sortKey, sortDir, page, size, total, totalPages, paginas, filtros(reserved keys excluded), q q String - current search text (round-tripped into the input) toastSeverity / toastMessage - optional OOB toast after row actions Columns mirror the legacy p:dataTable of secured/pages/CaByS/index.xhtml (Código monospace, Categoría, Descripción, Impuesto %) plus Estado and an Acciones column exposing the one write the REST API offers (PUT descripcion/estado). Filter parity: case-insensitive contains over codigo/descripcion (CabysController.globalFilterFunction port). WHAT CHANGED IN THE UI PASS --------------------------- - The wrapper is a _kit/surface (no title: the panel has no heading). It KEEPS its id, because that element IS the hx-target of the search input - the swap replaces the whole surface. - The 14-digit Codigo is an IDENTIFIER, so it stays left-aligned in .kit-code; only the Impuesto percentage is a quantity and carries `num`. NOTE: the column HEADERS are built server-side (the headers map of _kit/data-table), so the "num" flag on the header is out of this template's reach. !} {#include _kit/surface id=modelo.id} {#content}
