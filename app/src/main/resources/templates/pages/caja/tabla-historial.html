{! pages/caja/tabla-historial - ONE data-table include for the caja history (T38). Rendered standalone by GET /api/app/caja/table when the HX-Request header is present (fragment swap) AND included by index.html — single source of truth for the markup (T18 pattern). Model (identical contract to pages/loyalty/tabla-top.html): modelo Map - id, baseUrl, columnas(label/key), filas(pre-formatted row maps), sortKey, sortDir, page, size, total, totalPages, paginas, filtros(reserved keys excluded) Columns mirror the legacy p:dataTable of secured/pages/Caja/index.xhtml: Fecha Apertura, Fecha Cierre, Monto Inicial, Efectivo, SINPE, Tarjeta, Diferencia (green/red like .diferencia-positiva/.diferencia-negativa) and Estado (Abierta/Cerrada badge). Dates/money arrive pre-formatted from CierreCajaResource (legacy f:convertDateTime/f:convertNumber output). WHAT CHANGED IN THE UI PASS --------------------------- - The wrapper's .box frame and its
heading are gone: the panel around it is the _kit/surface in index.html ("Historial de Cierres"), so the table sits inside ONE frame instead of two and the panel's title is a real

. - The money columns are `num` cells: right-aligned with tabular figures. ROUND 2 ------- - The Estado cell printed the raw database value ("abierto"/"cerrado") in a saturated `tag is-success` / `tag is-danger` — white on Bulma success, about 1.9:1, and English-language-looking lowercase to boot. It is a pale status chip with the Spanish label now, and open/closed is not encoded as success/failure: an open shift is in progress, not "good". - A null difference printed a green em dash, because the server's diferenciaClass is has-text-success unless the amount is negative. The class is only applied when there IS a difference; a missing value is muted. The table's own heading (the surface h2) names it for screen readers, so no caption is injected inside the kit's tbody. - The empty state is a muted sentence instead of a grey table cell. !}
{#include _kit/data-table id=(modelo.id + '-tabla') baseUrl=modelo.baseUrl headers=modelo.columnas sortKey=modelo.sortKey sortDir=modelo.sortDir page=modelo.page size=modelo.size total=modelo.total totalPages=modelo.totalPages pages=modelo.paginas params=modelo.filtros} {#rows} {#for fila in modelo.filas} {#if fila.fechaApertura??}{fila.fechaApertura}{#else}—{/if} {#if fila.fechaCierre??}{fila.fechaCierre}{#else}—{/if} {#if fila.montoInicial??}{fila.montoInicial}{#else}—{/if} {#if fila.efectivo??}{fila.efectivo}{#else}—{/if} {#if fila.sinpe??}{fila.sinpe}{#else}—{/if} {#if fila.tarjeta??}{fila.tarjeta}{#else}—{/if} {#if fila.diferencia??} {fila.diferencia} {#else} — {/if} {#if fila.estado??} {#if fila.estado == 'abierto'}Abierta {#else}Cerrada{/if} {#else}Sin estado{/if} {#else} Todavía no hay cierres de caja registrados. {/for} {/rows} {/include}
