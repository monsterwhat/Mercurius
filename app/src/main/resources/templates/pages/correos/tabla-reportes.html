{! pages/correos/tabla-reportes - ONE data-table include for the Reportes Programados admin (W4B-CORREOS strangler view-half lane). Rendered standalone by GET /api/app/reportes-programados/table when HX-Request is present AND included by reportes.html — single source of truth for the markup (T18 pattern). Model (keys mirror the _kit/data-table DATA CONTRACT): modelo.id / baseUrl / columnas / filas / sortKey / sortDir / page / size / total / totalPages / paginas / filtros - kit contract q String - current search text isAdmin Boolean - legacy delete-button gate (rendered="#{SessionController.admin}") toastSeverity / toastMessage - optional OOB toast after row actions filas entries are precomputed maps: id, estado, perfil, frecuencia, reportes, correos, lastRun, nextRunTime (dates pre-formatted). Columns mirror the legacy p:dataTable of secured/pages/Correos/Reportes/ index.xhtml (chip estado / Nombre(perfil) / Correos / Frecuencia / Reportes / Acciones). Filter parity: globalFilterFunction over perfil/correos/reportes/frecuencia. Row actions: toggle (PUT /{id}/toggle), edit (data-kit-open), delete (admin-gated, hx-delete + hx-confirm). WHAT CHANGED IN THE UI PASS --------------------------- - The wrapper's .box frame is gone: the panel around it is the _kit/surface in reportes.html, so the table sits inside ONE frame instead of two. The id is still the hx-target, so a refresh swaps the table and the panel's title survives. - The row actions are icon-only buttons (kit icons, own aria-label) instead of emoji glyphs. Only the destructive one keeps is-danger; the rest are bordered buttons, because the teal accent is the screen's one filled primary. ROUND 2 ------- - The search field moved OUT of this fragment (it is in reportes.html now): it used to be inside the swap target, so every debounced search destroyed the input the operator was typing in. - `data-resultados` exposes the row count to the page's status region. - The toggle button says which way it will switch ("Habilitar" vs "Deshabilitar") in its aria-label and title; "Habilitar/Deshabilitar" is not an action name and it was the same string on every row. - Long report names and recipient lists are clamped to three lines with the full value in `title`, so one row cannot push the actions out of reach. - The empty state distinguishes "no hay reportes" from "la búsqueda no encontró nada", names the term, and offers the way back. - hx-disabled-elt="this" on toggle and delete: a double tap cannot fire the same mutation twice. !}
