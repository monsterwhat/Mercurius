{! pages/correos/tabla-plantillas - ONE data-table include for the Plantillas de Correo admin (W4B-CORREOS strangler view-half lane). Rendered standalone by GET /api/app/email-templates/table when the HX-Request header is present (fragment swap into the page's table container) AND included by templates.html — single source of truth for the markup (T18 pattern). Model (keys mirror the _kit/data-table DATA CONTRACT): modelo.id String - DOM id of the wrapper div ("tabla-plantillas") modelo.baseUrl String - "/api/app/email-templates/table" (context-relative) modelo.columnas List - header maps with label/key (key null ⇒ not sortable) modelo.filas List - precomputed rows: id, estado, nombre, tipo, tipoLabel, tipoBadge, asunto, fechaModificacion modelo.sortKey String - current sort column key (nullable) modelo.sortDir String - "asc"|"desc" modelo.page Integer - 1-based page modelo.size Integer - page size modelo.total Long - total rows after filter modelo.totalPages Integer - ceil(total/size), computed server-side modelo.paginas List - pager window modelo.filtros Map - preserved params; reserved keys excluded q String - current search text (drives the empty state) toastSeverity / toastMessage - optional OOB toast after row actions Columns mirror the legacy p:dataTable of secured/pages/Correos/Templates/ index.xhtml (chip estado / Nombre / Tipo badge / Asunto / Ultima Modificacion / Acciones). Filter parity: legacy matchesFilter() over nombre/tipo/asunto (case-insensitive contains). NOT ported: the per-row power-off toggle (the REST half exposes no template-toggle endpoint) and the preview dialog (needs a procesarPlantilla HTML endpoint that was not part of this lane's mandate). WHAT CHANGED IN THE UI PASS --------------------------- - The wrapper's .box frame is gone: the panel around it is the _kit/surface in templates.html, so the table sits inside ONE frame instead of two. The id is still the hx-target, so a refresh swaps the table and the panel's title survives. - The row actions are icon-only buttons (kit icons, own aria-label) instead of emoji glyphs. Only the destructive one keeps is-danger; the rest are bordered buttons, because the teal accent is the screen's one filled primary. ROUND 2 ------- - The search field moved OUT of this fragment (it is in templates.html now): it used to be inside the swap target, so every debounced search destroyed the input the operator was typing in. - `data-resultados` exposes the row count to the page's status region, which announces it after a swap. - Long template names and subjects are clamped to three lines with the full value in `title`; unclamped they stretched the table to any width and pushed the actions out of reach on a phone. - The empty state distinguishes "no hay plantillas" from "la búsqueda no encontró nada", names the term, and offers the way back. - hx-disabled-elt="this" on the delete button: a double tap cannot fire two DELETEs. !}
