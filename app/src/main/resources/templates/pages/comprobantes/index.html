Estas emisiones usan el mismo carrito del POS. Al abrir una tarjeta, el tipo de comprobante queda preseleccionado; agregue las líneas, asigne el cliente y complete la referencia en el diálogo de cobro.

Nota de débito (03)

Cargo adicional o anulación de una factura, tiquete, nota de crédito o comprobante de referencia.

Requiere cliente y referencia (tipo, número, fecha, código y motivo). No mueve inventario.

Emitir nota de débito

Factura de exportación (05)

Venta al exterior con receptor extranjero.

Requiere cliente (receptor extranjero) y las líneas del carrito. Descuenta inventario como una venta.

Emitir factura de exportación

Factura de compra (08)

El comprador documenta una compra a un proveedor no domiciliado.

Requiere cliente (proveedor), referencia 16 (proveedor no domiciliado) y código 11. Suma inventario.

Emitir factura de compra

Recibo de pago (10)

Documenta el pago de una venta a crédito.

Requiere cliente, referencia 17 (pago a comprobante) y condición de venta 09 u 11. No mueve inventario.

Emitir recibo de pago
Al facturar, el PDF se genera para impresión y el comprobante se puede reenviar por correo desde Facturas emitidas → detalle.
