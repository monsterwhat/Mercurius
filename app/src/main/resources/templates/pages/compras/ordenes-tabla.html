Model (identical contract to pages/clientes/tabla.html): modelo Map - id, baseUrl, columnas(label/key), filas(pre-computed row maps: id, numeroOrden, proveedorNombre, fecha, entrega, estado, estadoClass, total, puedeEditar, puedeCambiarEstado, puedeEliminar), sortKey, sortDir, page, size, total, totalPages, paginas, filtros(reserved keys excluded), q q String - current search text (round-tripped into the input) toastSeverity / toastMessage - optional OOB toast after row actions Columns mirror the legacy p:dataTable of Compras/Ordenes/index.xhtml: N° Orden, Proveedor, Fecha, Entrega Est., Estado(tag), Total + Acciones. WHAT CHANGED IN THE UI PASS --------------------------- - The wrapper's .box frame is gone: the panel around it is the _kit/surface in ordenes.html, so the table sits inside ONE frame instead of two. The id is still the hx-target, so a refresh swaps the table and the panel's title survive. - The row actions are icon-only buttons (kit icons, own aria-label) instead of emoji glyphs and per-row semantic hues. Only the destructive one keeps is-danger; the others are bordered buttons, because the teal accent is the screen's one filled primary. - The Total column is a `num` cell: right-aligned with tabular figures. !}
