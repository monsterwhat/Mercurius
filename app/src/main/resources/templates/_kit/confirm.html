{! _kit/confirm - styled confirmation dialog wired to htmx's hx-confirm (T16). Replaces the legacy p:confirm behavior / onclick confirm popups. Instead of the browser's native window.confirm (which htmx shows by default for elements carrying hx-confirm), this fragment installs the DOCUMENTED htmx customization hook: a listener on the "htmx:confirm" event that calls evt.preventDefault() and later evt.detail.issueRequest(true) when the user accepts. Any element with hx-confirm="¿texto?" therefore automatically gets this styled dialog: If a page does NOT include this fragment, htmx falls back to the native confirm - graceful degradation, no coupling.
