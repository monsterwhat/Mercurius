{! _kit/view-tabs - ONE visual tab system (W1). REPLACES the four pre-W1 mechanisms that all tried to be tabs: 1. Alpine `x-show` + `.stat-card` button bars (articulos, categorias, inventario, tributacion dashboard, consultas); 2. `.nav-card` pill buttons + `?seccion=` (tendencias, rendimiento, pronosticos, merma, alertas); 3. `.tabs.is-boxed` (reportes/margenes); 4. bare `?vista=` links styled ad hoc (reportes/resumen). The visual component is now identical everywhere. Only the STATE MECHANISM differs, and that is a caller decision: - server-driven view -> anchors with a query param (the common case); - purely local view -> Alpine `x-show` panels, tabs declared in the slot. PARAMS ariaLabel String - REQUIRED. Names the navigation landmark, e.g. "Vistas de articulos", "Consultas de facturas". tabs List - OPTIONAL. Data mode. One Map per tab exposing: key String - stable value written into the query param (?key=activos). label String - visible text. href String - OPTIONAL. When present the tab renders as . When absent it renders as {/if} {/for} {#else} {#insert tabs}{/insert} {/if}
