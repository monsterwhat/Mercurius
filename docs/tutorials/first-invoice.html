Primera Factura Electrónica

Tutorial paso a paso para crear y enviar su primera factura electrónica a Hacienda con Mercurius.

Prerrequisitos

Antes de comenzar, asegúrese de tener Mercurius ejecutándose (ver la guía de Primeros Pasos). Necesitará una conexión a Hacienda configurada con credenciales válidas para enviar facturas reales.

Paso 1: Descargar el Catálogo CABYS

Antes de crear productos, necesita el catálogo CABYS (Código de Actividades Económicas y Bienes y Servicios) de Hacienda. Este catálogo es obligatorio para identificar cada producto y servicio.

Si no tiene el catálogo descargado, solo verá un botón para importarlo directamente desde Hacienda.
1

Acceder al Catálogo CABYS

Vaya a Tributación > Catálogo CABYS.

2

Importar desde Hacienda

Si no tiene el catálogo, verá un botón Importar CABYS. Haga clic para descargarlo directamente desde los servicios de Hacienda. El proceso puede tomar unos minutos.

Primero, necesitamos un producto para facturar. Vaya a Inventario > Productos > Nuevo Producto.

Paso 3: Configurar Datos de la Empresa Emisora

Verifique que los datos de su empresa estén correctamente configurados. Vaya a Configuración > Datos de la Empresa.

Importante: Los datos de la empresa emisora deben coincidir exactamente con los registrados ante Hacienda. Cualquier discrepancia causará el rechazo del documento.
1

Campos requeridos

Asegúrese de completar cada uno de estos campos con la información exacta de su empresa:

  • Cédula Jurídica, número de cédula registrado ante Hacienda.
  • Nombre legal (razón social), denominación oficial de la empresa.
  • Nombre comercial, nombre bajo el cual opera.
  • Dirección física, dirección exacta registrada.
  • Teléfono, línea telefónica de la empresa.
  • Correo electrónico, correo electrónico oficial.
  • Código de actividad económica (CAEA), código asignado por Hacienda.
  • Situación fiscal, Activo, Inactivo, etc.
2

Guarde la configuración

Revise cada campo dos veces antes de guardar. Estos datos aparecerán en todos los comprobantes electrónicos que emita.

Paso 4: Configurar Certificado Digital

Para firmar documentos electrónicos, necesita un certificado digital P12 emitido por un proveedor autorizado por Hacienda.

El certificado digital es requerido para la firma XAdES-EPES. Sin un certificado válido, no será posible enviar documentos a Hacienda.
1

Obtener certificado P12

Adquiera su certificado digital de un proveedor autorizado por Hacienda (EJIE, Banco de Costa Rica, Firma & Cripto, entre otros).

2

Subir el certificado al sistema

Vaya a Tributación > Certificados > Nuevo Certificado. Suba el archivo .p12 e ingrese la contraseña del certificado.

3

Validación automática

El sistema validará el certificado automáticamente: verifica la fecha de vencimiento, el emisor y la coherencia con los datos de la empresa. Si todo es correcto, el certificado quedará habilitado para firma.

Paso 7: Firmar el Documento

Una vez validado el XML, firme el documento digitalmente. Mercurius aplica una firma XAdES-EPES utilizando su certificado P12.

1

¿Qué hace la firma XAdES?

  • Garantiza la autoría del documento, confirma que fue emitido por su empresa.
  • Protege contra modificaciones post-firma, cualquier alteración invalida la firma.
  • Cumple con los requisitos legales de Costa Rica para comprobantes electrónicos.
2

Proceso automático

Mercurius ejecuta la firma de forma transparente. El documento pasa de estado Generado a Firmado automáticamente al completar el proceso de firma XAdES-EPES.

Paso 8: Enviar a Hacienda

Envíe el documento firmado a la API MREC de Hacienda para su procesamiento.

1

Autenticación

Mercurius se autentica con Hacienda usando OIDC (OpenID Connect). El token se obtiene y almacena automáticamente.

2

Envío del documento

El XML firmado se transmite a la API MREC de Hacienda junto con la clave de acceso y el tipo de comprobante.

3

Respuesta de Hacienda

Hacienda valida y procesa el documento. El estado retornado puede ser:

  • Aceptado, el documento fue procesado correctamente.
  • Rechazado, Hacienda detectó un error. Consulte el mensaje de rechazo para corregirlo.
  • Procesando, el documento está en cola. Mercurius consultará el estado automáticamente.

Paso 9: Verificar el Estado

Después del envío, verifique el estado del documento en Tributación > Comprobantes Emitidos.

El documento atraviesa estos estados durante su ciclo de vida:

1

Borrador

Documento creado pero aún no procesado. Puede editarlo libremente.

2

Generado

XML generado y validado contra los esquemas XSD de Hacienda.

3

Firmado

Firma XAdES-EPES aplicada con su certificado digital P12.

4

Enviado

Documento transmitido a la API MREC de Hacienda.

5

Aceptado ✓

Hacienda aceptó el documento. El comprobante es legalmente válido.

Si Hacienda retorna "procesando", el sistema consultará automáticamente hasta recibir una respuesta final. No necesita realizar ninguna acción manual.

Paso 10: Generar el PDF

Una vez aceptado, genere el PDF del comprobante con código QR para impresión o envío al cliente.

El PDF incluye:

  • Datos del comprobante en formato oficial con todos los campos requeridos.
  • Código QR con la clave de acceso para verificación en el portal de Hacienda.
  • Desglose de impuestos con el detalle de IVA y cualquier otro gravamen aplicable.
  • Datos del emisor y receptor completos, incluyendo identificación y dirección.
