Despliegue en Producción

Guía para desplegar Mercurius en un entorno de producción.

Descripción General

Esta guía cubre los pasos necesarios para desplegar Mercurius en un servidor de producción.

Compilar para Producción

bash 
mvn clean package -Dquarkus.package.type=uber-jar

El uber-jar incluye todas las dependencias en un solo archivo JAR.

Configuración de Producción

Ajuste las propiedades de conexión y pool para el entorno de producción:

properties 
# Database (production)
quarkus.datasource.jdbc.url=jdbc:mysql://localhost:3306/mercurius?serverTimezone=America/Costa_Rica&useSSL=true
quarkus.datasource.jdbc.username=${DB_USERNAME}
quarkus.datasource.jdbc.password=${DB_PASSWORD}

# Schema strategy (do NOT use drop-and-create in production!)
quarkus.hibernate.orm.database.generation=none

# Connection pool
quarkus.datasource.jdbc.min-size=5
quarkus.datasource.jdbc.max-size=20

Importante: Nunca use drop-and-create en producción. Use none o validate para el esquema.

Certificados Digitales

Para la facturación electrónica con Hacienda, necesita un certificado digital P12:

  • Genere el certificado P12 con la información de su contribuyente.
  • Guárdelo en una ubicación segura con permisos restringidos.
  • Configure la ruta en application.properties.

Credenciales de Hacienda

Configure el acceso a la API de Hacienda para envío de comprobantes electrónicos:

  • Registre su contribuyente en el portal de Hacienda para obtener acceso a la API.
  • Configure las credenciales OIDC proporcionadas por Hacienda.
  • Almacene las credenciales cifradas con AES-256-GCM.

Ejecutar en Producción

bash 
java -jar target/mercurius-quarkus-1.0.0-SNAPSHOT-runner.jar

Configuración del Servidor

Para un despliegue estable en producción, considere los siguientes ajustes:

Proxy inverso con HTTPS

Coloque nginx o Apache frente a Mercurius para terminar TLS y servir el certificado SSL:

  • Certificado SSL wildcard o específico para su dominio.
  • Redirección automática de HTTP a HTTPS.
  • Compresión gzip para respuestas.

Ajustes de JVM

Optimice el rendimiento de la JVM con estas banderas:

bash 
java -Xms512m -Xmx2g -XX:+UseG1GC -XX:MaxGCPauseMillis=200 \
  -jar target/mercurius-quarkus-1.0.0-SNAPSHOT-runner.jar

Pool de conexiones

Ajuste el tamaño del pool según la carga esperada:

  • min-size=5 — Conexiones mínimas mantenidas en el pool.
  • max-size=20 — Conexiones máximas simultáneas.

Niveles de registro

Configure los logs para producción minimizando el ruido:

properties 
quarkus.log.level=INFO
quarkus.log.console.enable=false
quarkus.log.file.enable=true
quarkus.log.file.path=/var/log/mercurius/mercurius.log

Copias de Seguridad

Bajo Configuración > Copias de Seguridad, Mercurius ofrece un servicio de backup integrado.

Configure copias de seguridad periódicas de la base de datos MySQL. Combine el backup integrado con dump externo de MySQL para protección completa.

Monitoreo

Quarkus expone endpoints de salud y métricas listos para integrar con su sistema de monitoreo:

Endpoint Descripción
