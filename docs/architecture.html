Arquitectura

Arquitectura del sistema de inventario, facturación electrónica y punto de venta.

Descripción General

Mercurius es un sistema de inventario, punto de venta y facturación electrónica para Costa Rica. Soporta los 7 tipos de documento electrónico y se integra directamente con la API de Hacienda.

Modelo de Seguridad

Mercurius implementa un modelo de seguridad robusto con dos mecanismos de autenticación y seis roles definidos.

Mecanismos de autenticación

  • Sesión (JSF) — Para el panel de administración. Filtrado mediante SecurityFilter.

Flujo de Datos

Cada interacción en Mercurius sigue uno de estos caminos según el punto de origen:

  • Panel Admin → JSF/PrimeFaces → Quarkus REST → MySQL
  • Facturación Electrónica → Quarkus → External API (Fides) → Hacienda MREC
  • Firma Digital → XAdES-EPES → P12 Certificate → XML Firmado

Flujo de Facturación Electrónica

1

Crear Documento

El usuario crea un comprobante electrónico desde el punto de venta o el panel de administración.

2

Validar XSD

El sistema valida el XML contra los esquemas de Hacienda.

3

Firmar XAdES

Se aplica firma digital XAdES-EPES usando el certificado P12 del contribuyente.

4

Enviar a Hacienda

El documento firmado se envía a la API MREC de Hacienda para procesamiento.

5

Recibir Estado

Hacienda procesa y responde con aceptación, rechazo o procesando.

Seguridad de Datos

  • Cifrado AES-256-GCM para secretos en reposo (claves API, contraseñas de certificados).
  • Contraseñas con BCrypt (factor de trabajo 10).
  • Conexión a Hacienda mediante OIDC/ROPC con token caching.
