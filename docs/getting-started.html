Primeros Pasos

Instale, configure y ejecute Mercurius en su máquina en minutos.

Descripción General

Mercurius es un sistema completo de inventario y facturación electrónica para Costa Rica. Esta guía le ayudará a tener el sistema funcionando en su máquina de desarrollo.

Prerrequisitos

1

Java 25 (JDK 25)

Mercurius requiere Java 25 o superior. Descargue el JDK desde adoptium.org o use su gestor de versiones favorito.

bash 
java -version
# openjdk 25.0.1 2025-04-15
# OpenJDK Runtime Environment Temurin-25.0.1+8 (build 25.0.1+8)
# OpenJDK 64-Bit Server VM Temurin-25.0.1+8 (build 25.0.1+8, mixed mode, sharing)
2

MySQL 8.0+

El sistema utiliza MySQL como base de datos. Asegúrese de tener MySQL 8.0 o superior instalado y ejecutándose.

sql 
CREATE DATABASE mercurius;
CREATE USER 'mercurius'@'localhost' IDENTIFIED BY 'mercurius';
GRANT ALL PRIVILEGES ON mercurius.* TO 'mercurius'@'localhost';
FLUSH PRIVILEGES;
3

Maven 3.9+

Se requiere Maven para compilar el proyecto.

bash 
mvn -version
# Apache Maven 3.9.9

Clonar el Repositorio

bash 
git clone https://github.com/monsterwhat/Mercurius.git
cd Mercurius/mercurius-quarkus

Configurar la Base de Datos

Ajuste las propiedades de conexión en application.properties:

properties 
# Database
quarkus.datasource.jdbc.url=jdbc:mysql://localhost:3306/mercurius?serverTimezone=America/Costa_Rica
quarkus.datasource.jdbc.username=mercurius
quarkus.datasource.jdbc.password=mercurius

# Hibernate
quarkus.hibernate.orm.database.generation=drop-and-create

Compilar y Ejecutar

Modo desarrollo

Recomendado para la primera ejecución. Quarkus inicia con recarga en vivo y depuración remota.

bash 
mvn quarkus:dev

O use el script incluido:

batch 
.\run-dev.bat

Compilar uber-jar

Para generar un archivo JAR independiente con todas las dependencias:

bash 
mvn clean package -Dquarkus.package.type=uber-jar
java -jar target/quarkus-app.jar

Primera Ingreso

Una vez que el servidor esté en ejecución, abra su navegador y vaya a http://localhost:8081/Mercurius.

  • Usuario: admin
  • Contraseña: admin
  • En su primer ingreso, cambie la contraseña predeterminada por seguridad.

Navegación Principal

Una vez dentro del sistema, encontrará las siguientes secciones:

  • Dashboard — Panel principal con métricas en tiempo real.
  • Inventario — Gestión de productos, categorías y stock.
  • Facturación — Punto de venta y comprobantes electrónicos.
  • Tributación — Dashboard de Hacienda y consultas.
  • Reportes — Analítica y exportación.
  • Configuración — Ajustes del sistema y usuarios.

Configuración del Negocio

Antes de generar facturas electrónicas, necesita configurar los datos de su empresa y las credenciales de Hacienda. Todo se realiza desde Configuración dentro del sistema.

1

Datos de la Empresa

Registre la información legal de su compañía que aparecerá en todos los comprobantes electrónicos:

  • Cédula Jurídica — Número de cédula de la persona jurídica (formato: X-XXX-XXXXXX).
  • Nombre Legal — Razón social registrada ante Hacienda.
  • Nombre Comercial — Nombre que aparece en facturas y documentos.
  • Actividades Económicas (CAEA) — Códigos de actividad económica asignados por Hacienda.
  • Correo Electrónico — Email de contacto de la empresa.
2

Sucursales y Puntos de Venta

Configure las sucursales (sucursales) y puntos de venta autorizados por Hacienda:

  • Código de Sucursal — Código asignado por Hacienda (ej: 001).
  • Código de Terminal — Número de terminal o punto de venta (ej: 0001).

Cada sucursal puede tener múltiples puntos de venta. El sistema genera automáticamente el consecutivo de facturación basado en estos códigos.

3

Certificado Digital P12

El certificado digital se utiliza para firmar digitalmente cada documento electrónico con XAdES antes de enviarlo a Hacienda.

  • Obtenga su certificado digital P12 de un emisor autorizado por Hacienda.
  • Suba el archivo .p12 a través de Configuración > Certificados Digitales.
  • Ingrese la contraseña del certificado. La contraseña se almacena cifrada con AES-256-GCM.
4

Credenciales de Hacienda (API)

Mercurius necesita acceso a la API de Hacienda para enviar y consultar comprobantes electrónicos. Configure las credenciales OIDC:

  • Registre su contribuyente en el portal de Hacienda para obtener acceso a la API de Facturación Electrónica.
  • Ingrese el Client ID y Client Secret proporcionados por Hacienda.
  • Seleccione el ambiente: Staging (pruebas) o Producción.

Importante: Comience siempre en ambiente de pruebas (Staging) antes de enviar documentos reales a Hacienda.

5

Códigos CABYS

Cada producto o servicio que facture necesita un código CABYS (Código de Bienes y Servicios) de 13 dígitos asignado por Hacienda.

  • Mercurius descarga y gestiona la tabla de códigos CABYS directamente desde Hacienda, que se actualiza periódicamente.
  • Asigne el código CABYS correspondiente a cada producto en Inventario > Productos.
  • Si un producto está exento de IVA, registre la situación tributaria correcta.

API de Facturación Externa

Mercurius incluye un sistema integrado de facturación electrónica. Si prefiere delegar la generación, firma y envío de comprobantes a un servicio externo, puede configurar una API de facturación alternativa.

Fides

Fides es un servicio externo de facturación electrónica que se integra con Mercurius como backend de comprobantes.

Fides es un servicio privado. Si tiene acceso, contacte al administrador para obtener los detalles de conexión.

Conectar una API externa con Mercurius

Una vez que el servicio externo esté ejecutándose, configure la conexión en Mercurius:

  1. En Configuración, seleccione Tipo de Facturación > Externo.
  2. Ingrese la URL base del servicio (ej: http://localhost:3000).
  3. Ingrese un API Key válido generado desde el servicio.
  4. El sistema verificará la conexión automáticamente.

Cuando una API externa está habilitada, Mercurius delega la generación, firma y envío de XML. La interfaz de punto de venta y gestión de inventario se mantiene en Mercurius.

Mercatus — Tienda en Línea

Mercatus es una tienda en línea independiente que se conecta al backend de Mercurius para mostrar productos, gestionar carritos y procesar pedidos.

Mercatus es un servicio privado. Si tiene acceso, contacte al administrador para obtener los detalles de conexión.
