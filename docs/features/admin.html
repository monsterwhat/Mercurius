Administración

Gestión de usuarios, roles, configuración del sistema, copias de seguridad y registro de actividad.

Visión General

El módulo de administración de Mercurius le permite controlar todos los aspectos del sistema, desde la gestión de usuarios hasta la configuración avanzada. Incluye control de acceso basado en roles (RBAC), copias de seguridad automatizadas, registro de actividad completo y un sistema de alertas que mantiene al equipo informado sobre eventos críticos.

Usuarios

Crear, editar y desactivar usuarios con control de acceso basado en roles (RBAC). Gestión de credenciales, asignación de sucursales y seguimiento de actividad por usuario.

Roles

6 roles predeterminados (admin, facturación, inventario, usuario, tributación, registro) con permisos granulares por módulo. Soporte para roles personalizados con combinación de permisos específicos.

Clientes

Registro completo con datos fiscales (cédula, DIMEX, pasaporte), historial de compras y programa de puntos de lealtad. Soporte para clientes corporativos con datos de facturación múltiples.

Configuración

Ajustes generales de la aplicación, configuración de impresoras térmicas, directorio de archivos para documentos generados y temas de interfaz personalizables.

Copias de Seguridad

Servicio de backup integrado con programación automática, exportación de base de datos completa y posibilidad de restaurar a un punto específico. Almacenamiento local con verificación de integridad.

Registro de Actividad

Log completo de acciones del sistema con filtrado por usuario, fecha y tipo de acción. Trazabilidad total para auditorías internas y cumplimiento normativo.

Alertas

Sistema de notificaciones automáticas para eventos críticos: stock bajo, documentos rechazados por Hacienda, certificados por vencer y cambios de configuración sensibles.

Gestión de Usuarios

Gestión completa de usuarios con roles y permisos granulares para controlar quién puede acceder a cada funcionalidad del sistema.

  • Crear, editar y desactivar usuarios con perfiles completos
  • Asignación de roles con control de acceso basado en roles (RBAC)
  • Cambio de contraseña con políticas de seguridad configurables
  • Asignación de sucursales y puntos de venta
  • Bloqueo automático de cuentas después de intentos fallidos
  • Historial de actividad por usuario con timestamps
  • Soporte para autenticación con credenciales de Hacienda (facturación)

Roles del Sistema

Mercurius define 6 roles predeterminados, cada uno con permisos específicos diseñados para reflejar las responsabilidades típicas de un negocio. Los permisos se controlan a nivel de módulo y acción (lectura, escritura, eliminación).

Rol Permisos
admin Acceso total: configuración, usuarios, todos los módulos
facturacion Emisión, consulta y gestión de comprobantes electrónicos
inventario CRUD de productos, categorías, lotes, stock
usuario Consulta de productos, reportes básicos
tributacion Consultas a Hacienda, tipo de cambio, declaraciones
registro Gestión de usuarios y clientes

Gestión de Clientes

Mantenga un registro completo de sus clientes con toda la información fiscal necesaria para la facturación electrónica y el seguimiento de ventas.

  • Registro de clientes con datos fiscales completos (nombre, cédula, correo electrónico)
  • Tipos de identificación soportados: cédula física, cédula jurídica, DIMEX, pasaporte y identificación temporal
  • Historial completo de compras vinculado a facturación electrónica
  • Programa de puntos de lealtad con acumulación y canje configurable
  • Soporte para clientes corporativos con datos de facturación múltiples
  • Búsqueda rápida por nombre, cédula o correo electrónico
  • Segmentación de clientes por frecuencia de compra y monto promedio

Configuración del Sistema

Personalice Mercurius según las necesidades de su negocio con un panel de configuración completo.

  • Ajustes generales: nombre del negocio, número de cédula, datos del emisor para facturación
  • Configuración de impresoras térmicas para tickets y documentos de respaldo
  • Directorio de archivos para documentos generados (XML, PDF, reportes)
  • Temas de interfaz con soporte para modo claro y oscuro
  • Configuración de impuestos: tasa de IVA, productos exentos y sujetos a impuestos específicos
  • Parámetros de facturación: secuencias de documentos, moneda por defecto
  • Configuración de notificaciones y alertas del sistema

Copias de Seguridad

Mercurius incluye un servicio de backup integrado accesible desde Configuración > Copias de Seguridad. El sistema protege sus datos con copias automáticas y verificación de integridad.

  • Programación automática de backups con frecuencia configurable
  • Exportación de base de datos completa con todos los datos del sistema
  • Almacenamiento local con verificación de integridad mediante checksum
  • Posibilidad de restaurar el sistema a un punto específico de Backup
  • Historial de backups realizados con tamaño y fecha
  • Notificaciones de estado del proceso de backup (éxito, error, espacio insuficiente)

Recomendación — Configure backups automáticos diarios para proteger contra pérdida de datos. Los backups se almacenan localmente y pueden exportarse a almacenamiento externo.

Registro de Actividad

El sistema mantiene un registro completo y detallado de todas las acciones realizadas, proporcionando trazabilidad total para auditorías internas y cumplimiento normativo.

  • Log de todas las acciones del sistema: creación, edición, eliminación y consultas
  • Filtrado por usuario, fecha, tipo de acción y módulo afectado
  • Auditoría completa de cambios con valores anteriores y nuevos
  • Registro de intentos de acceso fallidos y actividad sospechosa
  • Exportación de registros de actividad para auditorías externas
  • Retención de registros configurable según políticas de la empresa

Alertas

Mercurius notifica automáticamente sobre eventos importantes del sistema, manteniendo al equipo informado sin necesidad de monitoreo constante.

  • Alertas de stock bajo — Notificaciones cuando los productos alcanzan el nivel mínimo configurado, con detalle del producto, cantidad actual y punto de pedido sugerido.
  • Documentos rechazados — Avisos inmediatos cuando Hacienda rechaza un comprobante, incluyendo el motivo del rechazo y pasos para corrección.
  • Certificados por vencer — Recordatorios 30 días antes de la fecha de expiración del certificado P12, con enlace directo a la configuración de renovación.
  • Modo contingencia activado — Notificación cuando el sistema entra en modo contingencia por indisponibilidad de Hacienda.
  • Cambios de configuración sensibles — Alertas cuando se modifican parámetros críticos como credenciales de Hacienda, datos del emisor o configuración de impuestos.
