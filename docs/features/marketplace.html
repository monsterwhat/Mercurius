Mercatus — Tienda en Línea

Aplicación frontend para clientes con catálogo, carrito de compras y pedidos auto-gestionados.

Visión General

Mercatus es la tienda en línea de Mercurius, una aplicación React que permite a sus clientes navegar el catálogo, agregar productos al carrito y realizar pedidos de forma auto-gestionada.

Stack Tecnológico

⚛️
React 19 + TypeScript
Frontend moderno con tipado estricto y componentes funcionales.
  • React 19 + TypeScript
  • Vite 8 (bundler)
  • Framer Motion (animaciones)
  • Lucide React (iconos)
  • React Router DOM (navegación)

Funcionalidades

Mercatus ofrece todo lo que sus clientes necesitan para comprar en línea.

  • Catálogo de productos con búsqueda y filtros
  • Detalle de producto con imágenes
  • Carrito de compras
  • Proceso de checkout
  • Registro e inicio de sesión (JWT)
  • Perfil de usuario
  • Historial de pedidos

Autenticación

Mercatus utiliza autenticación JWT separada del panel de administración. Los clientes se registran e inician sesión directamente desde la tienda.

Comunicación con el Backend

Mercatus se comunica con Mercurius a través de una API REST bajo /api/marketplace/. Los endpoints incluyen autenticación, productos, carrito, pedidos y perfil.

Endpoint Método Descripción
/api/marketplace/auth/register POST Registro de cliente
/api/marketplace/auth/login POST Inicio de sesión
/api/marketplace/auth/refresh POST Refrescar token
/api/marketplace/products GET Listar productos
/api/marketplace/cart GET/POST Gestionar carrito
/api/marketplace/orders GET/POST Gestionar pedidos
/api/marketplace/profile GET/PUT Perfil de usuario

Configuración

Para ejecutar Mercatus en desarrollo:

bash 
cd Mercatus
npm install
npm run dev

La aplicación estará disponible en http://localhost:5173
