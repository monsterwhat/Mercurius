Mercurius Primeros Pasos
Sistema de Inventario y Facturación

Mercurius

Sistema integral de inventario, punto de venta y facturación electrónica para Costa Rica. Cumplimiento total con Hacienda.

Arquitectura
Inventario

Gestión completa de productos, categorías, lotes, códigos de barras y control de stock con alertas y pronósticos.

Facturación Electrónica

Punto de venta integrado con los 7 tipos de documento: FE, TE, NC, ND, REP, FEC, FEE. Firma XAdES y envío a Hacienda.

Cumplimiento Tributario

Integración directa con Hacienda: catálogo CABYS, tipo de cambio, validación XSD y presentación de declaraciones.

Analítica y Reportes

Dashboard en tiempo real, tendencias de ventas, análisis de rentabilidad, estacionalidad y pronóstico de inventario.

API de Facturación Externa

Conecta servicios de facturación electrónica externos como Fides. Mercurius delega la generación, firma y envío de comprobantes a través de una API configurable.

Administración

Gestión de usuarios con 6 roles, copias de seguridad, registro de actividad y configuración del sistema.

Ecosistema Mercurius

Extensiones privadas que amplían las capacidades de Mercurius.

Fides

API de facturación electrónica independiente para generación, firma y envío de comprobantes a Hacienda. Se integra con Mercurius como backend de facturación externo.

Mercatus

Tienda en línea para clientes con catálogo digital, carrito de compras y pedidos auto-gestionados. Se conecta al backend de Mercurius a través de su API.

Tipos de Documento

Mercurius soporta los 7 tipos de documento electrónico definidos por Hacienda para la facturación electrónica.
