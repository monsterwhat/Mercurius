Facturación Electrónica

Punto de venta integrado con los 7 tipos de documento y firma digital XAdES.

Visión General

Mercurius integra un punto de venta completo con facturación electrónica cumpliendo el 100% de los requisitos de Hacienda para Costa Rica. Desde la emisión de comprobantes hasta el cierre de caja, cada paso del proceso está diseñado para ser rápido, seguro y compliant con la normativa vigente.

Punto de Venta

Interfaz intuitiva de venta rápida con búsqueda por código de barras, cálculo automático de impuestos (IVA 13%, Exento 4%) y soporte para múltiples métodos de pago en una sola transacción.

Tipos de Documento

7 tipos de comprobantes electrónicos soportados: Factura (FE), Tiquete (TE), Nota de Crédito (NC), Nota de Débito (ND), Recibo de Pago (REP), Factura de Compra (FEC) y Factura de Exportación (FEE).

Flujo Electrónico

Proceso automatizado de 5 pasos para cada documento: crear el XML, validar contra esquemas XSD, firmar digitalmente con XAdES, enviar a la API MREC de Hacienda y confirmar la aceptación.

Firma XAdES

Firma digital XAdES-EPES que garantiza autenticidad e integridad de cada comprobante. Los certificados P12 se almacenan de forma segura con cifrado en reposo y se renuevan automáticamente antes de su expiración.

Envío a Hacienda

Envío automático a la API MREC con manejo de respuestas asíncronas. Cuando Hacienda no está disponible, el sistema activa el modo contingencia y reintentos programados según la normativa.

Cierre de Caja

Control completo de caja con arqueo detallado, desglose por método de pago (efectivo, tarjeta, transferencia, puntos), cálculo automático de diferencias y reporte de cierre exportable.

Punto de Venta (POS)

La interfaz de venta está diseñada para agilizar el proceso de cobro en cualquier negocio, desde tiendas de conveniencia hasta restaurantes y servicios profesionales.

  • Interfaz intuitiva de venta rápida optimizada para pantallas táctiles
  • Selección de productos por código de barras, búsqueda por nombre o referencia
  • Cálculo automático de impuestos (IVA 13%, Exento 4%) con desglose visible
  • Métodos de pago múltiples: efectivo, tarjeta de crédito/débito, transferencia bancaria y puntos de lealtad
  • Soporte para ventas a crédito con seguimiento de cuentas por cobrar
  • Integración con impresora térmica para tickets y documentos de respaldo
  • Devoluciones y anulaciones con generación automática de notas de crédito

Tipos de Documento Soportados

Mercurius soporta los 7 tipos de comprobantes electrónicos definidos por Hacienda, cada uno con su caso de uso específico dentro del ciclo de facturación.

01 Factura Electrónica (FE) Documento principal de venta Ventas a clientes que requieren factura con datos fiscales completos
02 Tiquete Electrónico (TE) Ticket de venta menor a ₡137,000 Ventas al detal donde el cliente no solicita factura electrónica
03 Nota de Crédito (NC) Devoluciones y descuentos Devoluciones de mercadería, descuentos aplicados o correcciones a facturas emitidas

Flujo de Documento Electrónico

Cada documento electrónico sigue un proceso de 5 pasos hasta su validación definitiva. Este flujo está completamente automatizado y monitoreado por el sistema.

1

Crear

El POS genera el comprobante XML con todos los datos del emisor, receptor, líneas de detalle, impuestos aplicables y totales calculados automáticamente.

2

Validar

El XML se valida contra los esquemas XSD oficiales de Hacienda para cada tipo de documento. Se verifican estructura, tipos de datos, códigos CABYS y obligatoriedad de campos.

3

Firmar

Se aplica firma digital XAdES-EPES usando el certificado P12 del emisor. La firma garantiza la autenticidad del emisor y la integridad del contenido del documento.

4

Enviar

El documento firmado se envía a la API MREC de Hacienda. El sistema gestiona autenticación, reintentos automáticos y manejo de colas cuando el servicio presenta alta demanda.

5

Aceptar/Rechazar

Hacienda procesa el documento y responde con el estado (aceptado, rechazado o en proceso). El receptor tiene 1 día hábil para aceptar o rechazar. Mercurius gestiona automáticamente las notificaciones de estado.

Mensaje Receptor

El Mensaje Receptor es la respuesta del destinatario respecto a la aceptación o rechazo de un comprobante electrónico. Mercurius automatiza completamente este proceso, incluyendo:

  • Notificación automática al receptor cuando recibe un comprobante
  • Gestión del plazo de 1 día hábil para aceptar o rechazar
  • Aceptación explícita, aceptación tácita (vencimiento del plazo) y rechazo con motivo
  • Actualización automática del estado del documento en el sistema
  • Generación de notas de crédito para comprobantes rechazados

El receptor tiene 1 día hábil para aceptar o rechazar un comprobante electrónico. Si no responde dentro del plazo, el sistema registra la aceptación tácita automáticamente.

Código CABYS

Todos los productos incluyen el código CABYS (Clasificación de Actividades Económicas de Costa Rica) necesario para la facturación electrónica. Mercurius gestiona el catálogo de forma integral:

  • Sincronización automática del catálogo nacional desde Hacienda
  • Búsqueda y selección de códigos por descripción o código numérico
  • Validación de códigos CABYS al momento de crear productos
  • Mapeo entre productos del inventario y códigos del catálogo oficial
  • Soporte para códigos de bienes y servicios con impuestos exentos, gravados y sujetos a impuestos específicos

Cierre de Caja

Al finalizar la jornada, el sistema genera un reporte de cierre con el total de ventas, impuestos y pagos por método. Este reporte es esencial para la conciliación contable y el control diario del negocio.

  • Desglose de ventas por método de pago: efectivo, tarjeta de crédito, tarjeta de débito, transferencia bancaria y puntos de lealtad
  • Cálculo automático de IVA recaudado y exento del período
  • Arqueo de caja con comparación entre efectivo esperado y contado
  • Detección de diferencias y registro de sobrantes o faltantes
  • Exportación del reporte de cierre en formato PDF o Excel
  • Historial de cierres con acceso para consulta y auditoría
