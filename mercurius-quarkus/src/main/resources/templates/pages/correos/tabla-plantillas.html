{! pages/correos/tabla-plantillas - ONE data-table include for the Plantillas de Correo admin (W4B-CORREOS strangler view-half lane). Rendered standalone by GET /api/app/email-templates/table when the HX-Request header is present (fragment swap into the page's table container) AND included by templates.html — single source of truth for the markup (T18 pattern). Model (keys mirror the _kit/data-table DATA CONTRACT): modelo.id String - DOM id of the wrapper div ("tabla-plantillas") modelo.baseUrl String - "/api/app/email-templates/table" (context-relative) modelo.columnas List - header maps with label/key (key null ⇒ not sortable) modelo.filas List - precomputed rows: id, estado, nombre, tipo, tipoLabel, tipoBadge, asunto, fechaModificacion modelo.sortKey String - current sort column key (nullable) modelo.sortDir String - "asc"|"desc" modelo.page Integer - 1-based page modelo.size Integer - page size modelo.total Long - total rows after filter modelo.totalPages Integer - ceil(total/size), computed server-side modelo.paginas List - pager window modelo.filtros Map - preserved params; reserved keys excluded q String - current search text (round-tripped into input) toastSeverity / toastMessage - optional OOB toast after row actions Columns mirror the legacy p:dataTable of secured/pages/Correos/Templates/ index.xhtml (chip estado / Nombre / Tipo badge / Asunto / Ultima Modificacion / Acciones). Filter parity: legacy matchesFilter() over nombre/tipo/asunto (case-insensitive contains). NOT ported: the per-row power-off toggle (the REST half exposes no template-toggle endpoint) and the preview dialog (needs a procesarPlantilla HTML endpoint that was not part of this lane's mandate). !}
