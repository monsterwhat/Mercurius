{! _kit/pagination - Bulma pager for server-side paging (T16). Renders a centered Bulma pagination bar (prev / page numbers / next). To boost it, wrap the include in an element with hx-boost="true" or target the table container from the page. DATA CONTRACT (all supplied by the calling resource/template): page Integer - current page, 1-based.
